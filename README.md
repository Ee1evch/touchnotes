# Наставник — учебный помощник для планшета со стилусом

Android-приложение для планшета. Писать можно **где угодно**: в своём приложении для записей (Touchnotes,
Samsung Notes, OneNote, Squid, Nebo, Xodo, Flexcil, GoodNotes… — выбирается в настройках) или прямо
**в тетради «Наставника»** — с нажимом пера, маркером, ластиком, клеткой или линейкой, поверх фото и PDF.
Круглая кнопка висит поверх любого приложения.
Наставник работает **в фоне, без отдельного окна**. Спросил (кнопка → «Подсказка», «Где ошибка?», «Теория» или
своими словами) — наставник (Claude, Gemini, GPT или любая модель через прокси вроде Claudex) смотрит на снимок
экрана и **отвечает прямо на записи**: обводит место — ошибку или строку, где писать дальше — и ставит рядом
короткую заметку с формулами. Он **наводит**: подсказывает следующий шаг, показывает, где ошибка, объясняет теорию
на похожем примере. Решать он не будет. Может и сам следить за решением: когда перестаёшь писать, тихо проверяет
и отмечает ошибку, если она есть.
Когда решение верное, он предложит сделать **чистовик**: красивый конспект на листах A4 с формулами, таблицами
и графиками. Конспект сохраняется в PDF и PNG и сразу уходит в приложение для записей, а ещё выгружается в
Markdown, LaTeX и Word.

Предмет (матанализ, линейная алгебра, матлогика, физика…) наставник определяет сам по записям — выбирать его не нужно.

**Учебный цикл: решай → закрепи → повторяй.** Решил задачу — «Похожая задача» даст такую же на другие числа.
Каждый чистовик сам превращается в **карточки** «вопрос — ответ» (определения, теоремы, формулы из твоих записей),
и они возвращаются на повторение по интервалам: завтра, через 3 дня, неделю, 16 дней, месяц. Экран **«Прогресс»**
показывает серию дней подряд, активность за две недели и темы, где ты чаще ошибаешься. Вечером приходит
напоминание, если есть карточки и ты ещё не занимался. Наставника можно включать **плиткой в шторке**.

## Установка

### Вариант 1. Готовый APK из GitHub Actions (без Android SDK)

1. Открой вкладку **Actions** в репозитории → последний успешный запуск «Сборка APK».
2. Внизу, в **Artifacts**, скачай `nastavnik-debug-apk` (внутри архива `app-debug.apk`).
3. Перекинь `app-debug.apk` на планшет и открой. Android попросит разрешить установку из этого источника — разреши.
   Или по кабелю: `adb install -r app-debug.apk`.

Все сборки подписаны одним и тем же debug-ключом из репозитория (`app/debug.keystore`),
поэтому новая версия ставится поверх старой, и история не теряется.

### Вариант 2. Собрать самому на Windows

Нужны JDK 17+ и Android SDK. Проще всего поставить **Android Studio** (в ней есть и то, и другое),
открыть папку проекта и нажать *Build → Build APK(s)*. Только из командной строки (PowerShell):

```powershell
# 1. JDK 17
winget install EclipseAdoptium.Temurin.17.JDK

# 2. Android command-line tools
#    Скачай «Command line tools only» для Windows: https://developer.android.com/studio#command-tools
#    Распакуй так, чтобы получилось C:\Android\cmdline-tools\latest\bin\sdkmanager.bat
setx ANDROID_HOME C:\Android
$env:ANDROID_HOME = "C:\Android"
& C:\Android\cmdline-tools\latest\bin\sdkmanager.bat --licenses
& C:\Android\cmdline-tools\latest\bin\sdkmanager.bat "platform-tools" "platforms;android-36" "build-tools;35.0.0"

# 3. Сборка (в папке проекта)
.\gradlew.bat assembleDebug
# Готовый файл: app\build\outputs\apk\debug\app-debug.apk

# 4. Установка на подключённый планшет (включи «Отладку по USB» в «Для разработчиков»)
& C:\Android\platform-tools\adb.exe devices
& C:\Android\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
```

Юнит-тесты: `.\gradlew.bat testDebugUnitTest`.

## Первый запуск и разрешения

При первом запуске приложение само проведёт по шагам:

| Разрешение | Зачем |
|---|---|
| Поверх других окон | чтобы кнопка и ответы наставника появлялись поверх приложения для записей (обязательно) |
| Уведомления | чтобы Android не выключал наставника в фоне |
| Запись экрана | чтобы наставник видел записи. Система спрашивает при старте сессии, а на Android 14+ — **каждый раз заново**: выбирай «Весь экран» |
| Микрофон | вопросы голосом (можно пропустить) |

Потом выбери нейросеть, вставь API-ключ и нажми «Запустить наставника».

## Нейросеть и ключ

В *Настройках → Нейросеть* выбери, кто будет думать. Ключ для каждого провайдера хранится отдельно и
только на планшете, в зашифрованном виде (`EncryptedSharedPreferences`); в логи он не попадает.

| Провайдер | Где взять ключ | Модели по умолчанию |
|---|---|---|
| **Anthropic Claude** | console.anthropic.com → *Settings → API keys* (нужно пополнить баланс, обычно от $5) | `claude-sonnet-5-5`, `claude-haiku-5-5`, `claude-opus-5-5` |
| **Google Gemini** | aistudio.google.com/apikey → *Create API key*. **Подписка Google AI Pro ключ API не даёт**, но ключ в AI Studio создаётся бесплатно и работает в пределах бесплатного лимита | `gemini-flash-latest`, `gemini-pro-latest`, `gemini-flash-lite-latest` |
| **OpenAI-совместимый** | OpenAI: platform.openai.com/api-keys. OpenRouter: openrouter.ai/keys. Любой другой сервис с OpenAI-совместимым API (агрегаторы «много моделей в одном ключе», свой сервер) — его адрес и ключ | любая модель сервиса, которая понимает картинки |

| **Anthropic-совместимый прокси** | Claudex, CLIProxyAPI, claude-max-api-proxy и подобные: адрес прокси и токен (часто любой) | модели, которые отдаёт прокси (`claude-sonnet-4-5`, `gpt-5-codex`…) |

Для OpenAI-совместимых сервисов есть кнопки-заготовки адреса (OpenAI, OpenRouter) и поле «свой адрес» —
обычно он заканчивается на `/v1`, например `https://openrouter.ai/api/v1`.

### Ключи из Claudex и других прокси

Скопируй настройки из Claudex целиком — строки вида

```
export ANTHROPIC_BASE_URL=http://192.168.1.10:13456/proxy/codex
export ANTHROPIC_AUTH_TOKEN=sk-…
export ANTHROPIC_MODEL=gpt-5-codex
```

(или `OPENAI_BASE_URL` / `OPENAI_API_KEY`, или JSON из `settings.json`, или просто адрес и ключ двумя строками)
и нажми **«Вставить настройки из буфера»** в *Настройках → Нейросеть*. Приложение само выберет тип
(Anthropic- или OpenAI-совместимый), подставит адрес, ключ и модель.

Важно:
- `127.0.0.1` / `localhost` в настройках — это адрес **компьютера**, а не планшета. Замени его на адрес
  компьютера в домашней сети (`ipconfig` → IPv4, например `192.168.1.10`), а прокси запусти так, чтобы он
  слушал сеть (`host: 0.0.0.0` в конфиге CLIProxyAPI) и порт был открыт в брандмауэре Windows.
- Обычный `http://` разрешён (прокси в домашней сети редко бывают с https), но тогда ключ идёт по сети
  открытым текстом — приложение об этом предупреждает. Для работы вне дома нужен https-адрес.
- Как передавать токен, выбирается в настройках: «Оба заголовка» (по умолчанию: `x-api-key` и
  `Authorization: Bearer`), только Bearer или только `x-api-key`. Если прокси не требует ключа, поле можно
  оставить пустым.

Модель выбирается отдельно для наставника и для чистовика: готовые варианты, своё название или
**«Загрузить список моделей»** — приложение спросит у сервиса, какие модели доступны по твоему ключу, и
покажет список с поиском. «Проверить ключ» проверяет и ключ, и выбранную модель (бесплатно).

**Тренировка.** Вариант контрольной по теме или конспекту (решаешь в тетради, наставник знает ответы и проверит),
мини-тест с разбором ошибок, экзамены с обратным отсчётом — повторение карточек подстраивается под дату.
Ещё: поиск по всему, шпаргалка формул, «Проверь ответ», «Покажи шаг», режим контрольной, озвучка подсказок,
вопрос голосом, память о типичных ошибках, учёт расходов с дневным лимитом, резервная копия, виджет,
тёмная тема и обновление прямо из приложения.

## Как пользоваться

### Тетрадь в приложении

- **Новая тетрадь** — на главном экране («Пиши прямо здесь») или «Все тетради → Новая тетрадь»: клетка, линейка,
  точки или чистый лист. **Фото** (камера или галерея, до 30 снимков) и **PDF** (до 40 страниц) тоже становятся
  тетрадью — пиши прямо поверх. Фото и PDF можно прислать из любого приложения через «Поделиться» / «Открыть с помощью».
- **Перо** пишет с нажимом, без задержки (unbuffered-ввод). Обратный конец стилуса или кнопка на нём — ластик
  (стирает штрих целиком). Палец листает и масштабирует двумя пальцами (0,6–6×); ладонь на экране не мешает.
  «Палец рисует» — переключатель в палитре. Ручки: синяя, чёрная, красная, зелёная; маркеры: жёлтый, розовый,
  голубой; три толщины. «Назад» / «Вперёд» — до 200 шагов на каждой странице. Сохраняется само, через 0,8 с.
- **Наставник справа** (на телефоне — снизу): «Подсказка», «Где ошибка?», «Проверь ответ», «Теория», «Покажи шаг»,
  «Похожая», «Контрольная», вопрос текстом или голосом. Он видит **всю тетрадь** (текущую страницу и соседние) и
  ставит **нумерованные метки прямо на листе**, а текст — в панели под теми же номерами: записи не закрываются.
  «показать ↗» прокручивает лист к метке. «Проверять, когда остановлюсь» — тихая проверка через 7 с паузы.
- **Контрольная**: 20/45/60/90 минут, наставник молчит до «Сдать работу», потом проверяет всё и ставит оценку.
- **«В карточки +»** под любой заметкой — нейросеть делает из подсказки карточку «вопрос — ответ» для повторения
  (так же — значок карточек в заметке поверх других приложений).
- **Озвучка** — значок динамика у заметки; «Читать подсказки вслух» в настройках — автоматически.

### Тренировка, экзамены, поиск

- **Тренировка → Вариант**: тема или конспект → 3, 5 или 8 задач от разминки до «с подвохом». «Решать в тетради»
  создаёт тетрадь с условиями в панели; наставник знает ответы, «Проверь ответ» сверяет, но не выдаёт ответ раньше.
- **Тренировка → Мини-тест**: 8 вопросов с вариантами, после ответа — верно/неверно и почему; итог и
  «Ошибки в карточки».
- **Тренировка → Экзамены**: предмет и дата. На главном — «Матанализ: экзамен через 9 дней»; карточки этого
  предмета повторятся не позже утра накануне. «Готовиться» — сразу вариант по предмету.
- **Поиск** (лупа на главном): чистовики, ответы наставника, тетради, карточки; без учёта регистра и «ё».
- **История → Чистовики**: «Шпаргалка к экзамену» (все определения, теоремы и формулы без повторов, по предметам →
  PDF), «Экспорт» каждого чистовика в Markdown, LaTeX (Overleaf) или Word.

### Удобство

- **Настройки → Расходы**: сегодня, 7 и 30 дней, дневной лимит ($0.10–$3 или без лимита). Для Claude — точные
  токены от сервера, для остальных — оценка. **Оформление**: светлая, тёмная или как в системе.
  **Резервная копия**: всё в один zip (без ключей) и восстановление. **Обновления**: свежая сборка с GitHub
  ставится поверх, записи сохраняются (нужно один раз разрешить установку из «Наставника»).
- **Виджет** «Наставник» на рабочем столе: карточки на сегодня, серия, экзамен; «Повторить», «Тетрадь», «Наставник».

### Поверх своего приложения для записей

- **Кнопка.** Палец — короткое меню рядом с кнопкой. Стилус кнопку не нажимает: если поднести перо, кнопка на 1,5 с
  становится «прозрачной» для касаний, и штрих уходит в приложение для записей. Перетаскивай пальцем, кнопка прилипнет к краю.
  Долгое нажатие — «Следить за решением», «Выделять область», «Новая задача», «Пролистать весь конспект»,
  «Забыть конспект», «История», «Повторить карточки», «Настройки», «Спрятать», «Выключить».
- **Меню у кнопки.** «Подсказка», «Где ошибка?», «Проверь ответ», «Покажи шаг», «Теория», «Похожая задача»,
  «Спросить голосом» (сразу слушает и отправляет) — каждое нажатие делает свежий снимок экрана (без наших
  окон и строки состояния) и задаёт вопрос. «Спросить…» — строка для вопроса своими словами, с микрофоном.
  Пока наставник думает, по кромке кнопки бежит тёмная дуга. Кнопка, меню и заметки — «жидкое стекло»:
  полупрозрачные светлые пластины, сквозь которые видны записи.
- **Ответ на записи.** Нужная строка подсвечена как маркером: красным с волнистым подчёркиванием — ошибка,
  зелёным — верный шаг, янтарным — к чему относится теория; серое пунктирное место под строкой — где писать
  следующий шаг. Подсветка точная: приложение само находит строки на снимке и подписывает их номерами на поле
  слева, наставник называет номер строки, и подсветка ложится ровно по чернилам. Внутри подсветки можно писать.
- **Заметка — коротко, «Подробнее» — полностью.** Сначала видна только короткая подсказка в одну фразу — узкая
  стеклянная заметка почти ничего не закрывает, а записи под ней просвечивают. «Подробнее» раскрывает полную
  подсказку (почему, какое правило, похожий пример), «Коротко» сворачивает обратно.
- **Заметка** стоит рядом со строкой, «хвостиком» к ней, на пустом месте листа (приложение ищет, где нет записей).
  Её можно перетащить за заголовок с точками — пальцем или стилусом; поставленная вручную, она остаётся там.
  Поднеси стилус к тексту заметки — она станет прозрачной и пропустит штрих. Кнопка-глаз в заголовке прячет
  выделение на записи (и показывает снова), заметка при этом остаётся. Внизу «Ещё подсказка» (или «Похожая
  задача» и «Сделать чистовик», если решение готово). Сама заметка не исчезает — только по крестику,
  «Убрать заметки» в меню или новому вопросу.
- **Весь конспект.** Наставник видит не только экран. Страница, где ты спросил, и всё, что ты потом спокойно
  пролистал в этой тетради, запоминаются, и при следующем вопросе уходят вместе с текущим экраном (до 8 страниц
  по порядку тетради). Так он видит условие задачи, определения и прошлые шаги, даже если они на другой
  странице. Чтобы показать конспект целиком: долгое нажатие на кнопку → «Пролистать весь конспект» → листай от
  начала до конца, задерживаясь на каждом экране на секунду → «Готово». «Забыть конспект» — там же. Страницы
  хранятся только на планшете и забываются через 12 часов; выключить — *Настройки → Весь конспект → Только экран*.
  В чистовике появится кнопка «Весь конспект (N)» — чистовик соберётся из всех запомненных страниц.
- **Прокрутка.** Пока ответ на экране, приложение раз в 2 с смотрит на уменьшенный кадр экрана (он никуда не
  отправляется). Прокрутил страницу — подсветка и заметка едут вместе с записями; если строка ушла за край,
  подсветка прячется, а заметка остаётся у края экрана.
- **Увеличение и поворот.** Если страницу увеличили, уменьшили или повернули планшет, подсветка на секунду
  прячется. Как только картинка успокоится, приложение делает свежий снимок, заново находит строки и узнаёт
  отмеченную строку по её рисунку с учётом нового масштаба — подсветка встаёт туда, где строка теперь.
  Открыл другую страницу, где этой строки нет, — подсветка остаётся скрытой, заметка на месте.
- **Следить за решением** (долгое нажатие или настройки; по умолчанию выключено). Когда ты пишешь и
  останавливаешься на 5–20 с, наставник сам проверяет решение. Нашёл ошибку — обводит её; всё верно — кнопка
  мигает зелёным. Не чаще раза в 45 с, и пока на экране ответ на твой вопрос, тихая проверка его не перебивает.
  Каждая проверка — платный запрос к нейросети.
- **Область.** «Выделять область перед вопросом» в меню долгого нажатия: после вопроса обведи пальцем задачу,
  и уйдёт только она. Рамки всё равно лягут на нужное место экрана.
- **Новая задача** начинается сама, если наставника не спрашивали 40 минут, или из меню долгого нажатия.
- **Чистовик.** «Чистовик» в меню (или «Сделать чистовик» в заметке, когда решение верное) → снимок экрана.
  У кнопки появится строка «Чистовик · снимков: 1». Конспект длиннее экрана: прокрути записи и нажми
  «+ Экран» (до 8 снимков) → «Собрать» → приложение само откроет предпросмотр → «Сохранить».
  Файлы: `Документы/Конспекты/<Предмет>/<Тема> — <дата>.pdf` и PNG каждой страницы рядом.
  PDF сразу отправляется в приложение для записей. Если его нет, откроется обычное «Поделиться».
  Куда отправлять по умолчанию, выбирается в настройках.
- **История** (меню долгого нажатия или главный экран): прошлые задачи по дням — каждая названа по теме,
  которую узнал наставник (её можно продолжить), и чистовики (открыть, отправить ещё раз, отправить картинками).
- **Похожая задача** — пункт в меню кнопки и кнопка в заметке, когда решение верное: наставник придумывает
  задачу на тот же метод с другими числами (без решения).
- **Повторение** (главный экран, ярлык на значке приложения или «Повторить карточки» в меню долгого нажатия).
  Карточки появляются сами из каждого сохранённого чистовика. Вопрос → ответь про себя → «Показать ответ» →
  «Помню» (карточка вернётся позже: завтра, через 3, 7, 16, 35 дней) или «Не помню» (ещё раз в этой же
  тренировке, потом с начала). Попробовать можно на встроенном примере, не делая чистовика.
- **Прогресс**: серия дней подряд (занятие — любой вопрос наставнику, чистовик или повторённая карточка),
  столбики за 14 дней (коснись столбика — увидишь число), сколько ошибок нашёл наставник, сколько карточек
  выучено и «Где чаще ошибаешься» — темы с ошибками за 30 дней.
- **Напоминание** о карточках — раз в день (по умолчанию в 18:00), только если есть что повторить и сегодня ты
  ещё не занимался. Время или «Не напоминать» — в *Настройках → Повторение*.
- **Плитка в шторке.** Опусти шторку → карандаш → перетащи плитку «Наставник». Одно касание включает или
  выключает кнопку поверх записей. Долгое нажатие на значок приложения — ярлыки «Запустить», «Повторение»,
  «Прогресс».
- **Плитка «Чистовик»** на главном экране показывает текущий чистовик, а если его нет — как его сделать и
  «Посмотреть пример»: встроенный конспект (формулы, таблица, график) без нейросети. Им можно проверить
  шаблон, PDF и отправку в приложение для записей.
- **Ошибка сети** — в сообщении у кнопки есть «Повторить». Если в это время шла фоновая проверка, твой вопрос
  её останавливает, а не ждёт.

## Если что-то не так

- *«Не задан API-ключ» / «Неверный API-ключ (401)»* — Настройки → Нейросеть → «Проверить ключ».
  Ключ сохраняется сразу, как только вставлен в поле, — отдельная кнопка «Сохранить» не нужна.
- *Прокси не отвечает* — планшет и компьютер в одной сети? В адресе IP компьютера, а не `127.0.0.1`?
  Прокси слушает `0.0.0.0`, порт открыт в брандмауэре? Проверь, открыв `http://<IP>:<порт>/v1/models` в браузере планшета.
- *«Модель не найдена (404)»* — Настройки → Модель → «Загрузить список моделей» и выбери из списка.
- *«На балансе закончились средства»* — пополни баланс у провайдера.
- *429 / 529* — слишком много запросов или серверы перегружены: подожди минуту.
- *«Нет разрешения на снимок экрана»* — нажми кнопку ещё раз и в системном окне выбери «Весь экран».
- Кнопка пропала — проверь уведомление «Наставник рядом» (там есть «Показать кнопку»), или запусти приложение снова.
