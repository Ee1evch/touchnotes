# Наставник — помощник поверх Touchnotes

Android-приложение для планшета. Круглая кнопка висит поверх **Touchnotes** (и любого другого приложения).
Нажал пальцем → снизу всплывает карточка в стиле Gemini → наставник (Claude, Gemini, GPT или любая модель через
прокси вроде Claudex) смотрит на снимок экрана и **наводит**:
подсказывает следующий шаг, ищет, где ошибка, объясняет теорию на похожем примере. Решать он не будет.
Когда решение верное, он предложит сделать **чистовик**: красивый конспект на листах A4 с формулами, таблицами
и графиками. Конспект сохраняется в PDF и PNG и сразу уходит в Touchnotes.

Предметы по умолчанию: матанализ, линейная алгебра, матлогика, физика (можно вписать свой).

## Установка

### Вариант 1. Готовый APK из GitHub Actions (без Android SDK)

1. Открой вкладку **Actions** в репозитории → последний успешный запуск «Сборка APK».
2. Внизу, в **Artifacts**, скачай `nastavnik-debug-apk` (внутри архива `app-debug.apk`).
3. Перекинь `app-debug.apk` на планшет и открой. Android попросит разрешить установку из этого источника — разреши.
   Или по кабелю: `adb install -r app-debug.apk`.

Все сборки подписаны одним и тем же debug-ключом из репозитория (`app/debug.keystore`),
поэтому новая версия ставится поверх старой, и история не теряется.

### Вариант 2. Собрать самому на Windows

Нужны JDK 17+ и Android SDK. Проще всего поставить **Android Studio** (в ней есть и то, и другое),
открыть папку проекта и нажать *Build → Build APK(s)*. Только из командной строки (PowerShell):

```powershell
# 1. JDK 17
winget install EclipseAdoptium.Temurin.17.JDK

# 2. Android command-line tools
#    Скачай «Command line tools only» для Windows: https://developer.android.com/studio#command-tools
#    Распакуй так, чтобы получилось C:\Android\cmdline-tools\latest\bin\sdkmanager.bat
setx ANDROID_HOME C:\Android
$env:ANDROID_HOME = "C:\Android"
& C:\Android\cmdline-tools\latest\bin\sdkmanager.bat --licenses
& C:\Android\cmdline-tools\latest\bin\sdkmanager.bat "platform-tools" "platforms;android-36" "build-tools;35.0.0"

# 3. Сборка (в папке проекта)
.\gradlew.bat assembleDebug
# Готовый файл: app\build\outputs\apk\debug\app-debug.apk

# 4. Установка на подключённый планшет (включи «Отладку по USB» в «Для разработчиков»)
& C:\Android\platform-tools\adb.exe devices
& C:\Android\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
```

Юнит-тесты: `.\gradlew.bat testDebugUnitTest`.

## Первый запуск и разрешения

При первом запуске приложение само проведёт по шагам:

| Разрешение | Зачем |
|---|---|
| Поверх других окон | чтобы кнопка и панель висели поверх Touchnotes (обязательно) |
| Уведомления | чтобы Android не выключал наставника в фоне |
| Запись экрана | чтобы наставник видел записи. Система спрашивает при старте сессии, а на Android 14+ — **каждый раз заново**: выбирай «Весь экран» |
| Микрофон | вопросы голосом (можно пропустить) |

Потом выбери нейросеть, вставь API-ключ и нажми «Запустить наставника».

## Нейросеть и ключ

В *Настройках → Нейросеть* выбери, кто будет думать. Ключ для каждого провайдера хранится отдельно и
только на планшете, в зашифрованном виде (`EncryptedSharedPreferences`); в логи он не попадает.

| Провайдер | Где взять ключ | Модели по умолчанию |
|---|---|---|
| **Anthropic Claude** | console.anthropic.com → *Settings → API keys* (нужно пополнить баланс, обычно от $5) | `claude-sonnet-5-5`, `claude-haiku-5-5`, `claude-opus-5-5` |
| **Google Gemini** | aistudio.google.com/apikey → *Create API key*. **Подписка Google AI Pro ключ API не даёт**, но ключ в AI Studio создаётся бесплатно и работает в пределах бесплатного лимита | `gemini-flash-latest`, `gemini-pro-latest`, `gemini-flash-lite-latest` |
| **OpenAI-совместимый** | OpenAI: platform.openai.com/api-keys. OpenRouter: openrouter.ai/keys. Любой другой сервис с OpenAI-совместимым API (агрегаторы «много моделей в одном ключе», свой сервер) — его адрес и ключ | любая модель сервиса, которая понимает картинки |

| **Anthropic-совместимый прокси** | Claudex, CLIProxyAPI, claude-max-api-proxy и подобные: адрес прокси и токен (часто любой) | модели, которые отдаёт прокси (`claude-sonnet-4-5`, `gpt-5-codex`…) |

Для OpenAI-совместимых сервисов есть кнопки-заготовки адреса (OpenAI, OpenRouter) и поле «свой адрес» —
обычно он заканчивается на `/v1`, например `https://openrouter.ai/api/v1`.

### Ключи из Claudex и других прокси

Скопируй настройки из Claudex целиком — строки вида

```
export ANTHROPIC_BASE_URL=http://192.168.1.10:13456/proxy/codex
export ANTHROPIC_AUTH_TOKEN=sk-…
export ANTHROPIC_MODEL=gpt-5-codex
```

(или `OPENAI_BASE_URL` / `OPENAI_API_KEY`, или JSON из `settings.json`, или просто адрес и ключ двумя строками)
и нажми **«Вставить настройки из буфера»** в *Настройках → Нейросеть*. Приложение само выберет тип
(Anthropic- или OpenAI-совместимый), подставит адрес, ключ и модель.

Важно:
- `127.0.0.1` / `localhost` в настройках — это адрес **компьютера**, а не планшета. Замени его на адрес
  компьютера в домашней сети (`ipconfig` → IPv4, например `192.168.1.10`), а прокси запусти так, чтобы он
  слушал сеть (`host: 0.0.0.0` в конфиге CLIProxyAPI) и порт был открыт в брандмауэре Windows.
- Обычный `http://` разрешён (прокси в домашней сети редко бывают с https), но тогда ключ идёт по сети
  открытым текстом — приложение об этом предупреждает. Для работы вне дома нужен https-адрес.
- Как передавать токен, выбирается в настройках: «Оба заголовка» (по умолчанию: `x-api-key` и
  `Authorization: Bearer`), только Bearer или только `x-api-key`. Если прокси не требует ключа, поле можно
  оставить пустым.

Модель выбирается отдельно для наставника и для чистовика: готовые варианты, своё название или
**«Загрузить список моделей»** — приложение спросит у сервиса, какие модели доступны по твоему ключу, и
покажет список с поиском. «Проверить ключ» проверяет и ключ, и выбранную модель (бесплатно).

## Как пользоваться

- **Кнопка.** Палец — открыть панель. Стилус кнопку не нажимает: если поднести перо, кнопка на 1,5 с
  становится «прозрачной» для касаний, и штрих уходит в Touchnotes. Перетаскивай пальцем, кнопка прилипнет к краю.
  Долгое нажатие — меню «Спрятать на 10 минут / Настройки / Выключить».
- **Окно наставника** — плавающая карточка снизу с радужной подсветкой, как у Gemini. В альбомной ориентации
  она занимает меньше половины ширины и стоит у той стороны, где кнопка; в портретной — по ширине экрана.
  Высота подстраивается под ответ. **Пока ты пишешь стилусом мимо карточки, она не исчезает**, а только
  становится полупрозрачной; коснись её — снова яркая, а когда ответ готов, она «просыпается» сама.
  Свернуть: смахни карточку вниз или нажми «Свернуть». Непрозрачность при письме и автосворачивание
  (по умолчанию выключено) — в *Настройках → Окно наставника*.
- **Быстрые кнопки.** «Подскажи следующий шаг», «Проверь, где ошибка», «Объясни теорию» — каждое нажатие делает
  свежий снимок экрана (без самой кнопки и панели, без строки состояния) и задаёт вопрос. Ответ печатается сразу.
- **Своими словами.** Внизу поле ввода и микрофон. Значок камеры слева — прикладывать ли снимок к такому вопросу.
- **Область.** Значок рамки в шапке включает режим «Выделить область»: после нажатия кнопки обведи пальцем задачу,
  и уйдёт только она.
- **Предмет** меняется тапом по подписи под заголовком панели.
- **Чистовик.** «Сделать чистовик» → снимок экрана. Конспект длиннее экрана: прокрути Touchnotes и нажми
  «+ Добавить экран» (до 5 снимков) → «Собрать чистовик» → предпросмотр → «Сохранить».
  Файлы: `Документы/Конспекты/<Предмет>/<Тема> — <дата>.pdf` и PNG каждой страницы рядом.
  PDF сразу отправляется в Touchnotes. Если Touchnotes не найден, откроется обычное «Поделиться».
  Куда отправлять по умолчанию, выбирается в настройках.
- **История** (меню ⋮ в панели или главный экран): прошлые задачи (можно продолжить) и чистовики (открыть,
  отправить ещё раз, отправить картинками).
- **Тест чистовика** на главном экране рисует встроенный пример (формулы, таблица, график) без API. Им можно
  проверить шаблон, PDF и отправку в Touchnotes.

## Если что-то не так

- *«Не задан API-ключ» / «Неверный API-ключ (401)»* — Настройки → Нейросеть → «Проверить ключ».
- *Прокси не отвечает* — планшет и компьютер в одной сети? В адресе IP компьютера, а не `127.0.0.1`?
  Прокси слушает `0.0.0.0`, порт открыт в брандмауэре? Проверь, открыв `http://<IP>:<порт>/v1/models` в браузере планшета.
- *«Модель не найдена (404)»* — Настройки → Модель → «Загрузить список моделей» и выбери из списка.
- *«На балансе закончились средства»* — пополни баланс у провайдера.
- *429 / 529* — слишком много запросов или серверы перегружены: подожди минуту.
- *«Нет разрешения на снимок экрана»* — нажми кнопку ещё раз и в системном окне выбери «Весь экран».
- Кнопка пропала — проверь уведомление «Наставник рядом» (там есть «Показать кнопку»), или запусти приложение снова.

## Проверка

- `.\gradlew.bat testDebugUnitTest` — юнит-тесты (SSE, сборка запроса, ошибки API, парсер чистовика, `[[ГОТОВО]]`).
- `.\gradlew.bat connectedDebugAndroidTest` — тесты на подключённом устройстве или эмуляторе: кнопка, стилус,
  панель, снимок экрана, область, чистовик → PDF. В GitHub Actions они идут на эмуляторе планшета (задание `smoke`).
- В отладочной сборке последний отправленный снимок лежит в кэше приложения (`last_shot.jpg`).
